# Cafe Moment

간단한 카페 랜딩페이지입니다. 순수 HTML/CSS/JavaScript로 제작되었으며 별도의 빌드 과정이나 의존성 설치 없이 바로 사용할 수 있습니다.

## 구성

- `index.html` — 페이지 마크업 (헤더, 히어로, 소개, 메뉴, 갤러리, 오시는 길, 푸터)
- `style.css` — 스타일 (반응형 레이아웃 포함)
- `script.js` — 모바일 내비게이션 토글, 스크롤 헤더 효과

## 실행 방법

`index.html` 파일을 브라우저에서 바로 열면 됩니다.

```bash
open index.html
```
